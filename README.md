Este repositorio implementa una Arquitectura Empresarial Dinámica (DYA) basada en el paradigma Medallion (Bronze, Silver, Gold), diseñada para procesar, transformar y exponer grandes volúmenes de datos en Google Cloud Platform (BigQuery y Dataform). El diseño prioriza la idempotencia, la modularidad analítica, el desacoplamiento de capas y estrictas pruebas de calidad de datos orientadas a la toma de decisiones ejecutivas.
